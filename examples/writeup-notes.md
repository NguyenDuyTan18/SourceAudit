# Ghi chú minh họa — không phải bằng chứng trên mục tiêu

SQL injection: kiểm tra dữ liệu đầu vào có đi vào SQL ghép chuỗi.
XSS: kiểm tra ngữ cảnh xuất HTML và sanitizer trước khi kết luận.
Prototype pollution: xem thao tác merge object nhận dữ liệu ngoài.
