# SrcAudit quickstart

[Start SrcAudit with Docker Compose](../README.md#run-with-docker-compose) to get the local web app and Semgrep in one container. [Run directly with Node.js](../README.md#run-directly-with-nodejs) if you prefer a native installation.

In the web app, choose a ZIP file or folder, select **Quick scan** or **Deep scan with Semgrep**, and select **Start scan**. Try the `examples/demo-src` directory from the checkout. Review **Scan results** and check the coverage before exporting HTML, JSON, text or SARIF.

For the command line, see [Docker CLI](../README.md#docker-cli) and [CLI and CI](../README.md#cli-and-ci).
